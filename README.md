# indic-scheme-rag (Pakkam)

**Multilingual Citizen-Scheme Assistant**: a citation-grounded RAG assistant that answers questions
about public Indian government schemes in **Tamil, Hindi, English and Tamil-English mixed (Tanglish)**
text and voice, providing auditable source citations, deterministic claim verification, and strict refusal guardrails.

> **Disclaimer.** This is an independent student research prototype. It is **not** an official service and is
> **not affiliated with any government body**. Answers are informational only and must be verified
> with the official source or office before acting on them. It uses only publicly available documents
> (cataloged in [docs/sources.csv](docs/sources.csv)) and stores no personal data.

---

## Target State Architecture & How it Works

```
User Query (Text or Voice via Gnani Prisma v2.5 STT)
                           │
             Unicode / Numeral Normalization
                           │
         ┌─────────────────┴─────────────────┐
         ▼                                   ▼
 [Verified Fact Card?]              [General Query]
 Exact scheme + intent match        Hybrid First-Stage Retrieval (BAAI/bge-m3)
       │                                     │
   [YES: Match]                     ┌────────┴────────┐
 Returns Verified Card              ▼                 ▼
 0 LLM calls, <50ms           Dense (Cosine)    Sparse (ColBERT)
 Pre-cached Indic TTS Audio         └────────┬────────┘
                                             ▼
                                Reciprocal Rank Fusion (Qdrant)
                                             │
                                  Cross-Encoder Reranking
                                 (BAAI/bge-reranker-v2-m3)
                                             │
                                 Confidence Score < 0.35?
                                ┌────────────┴────────────┐
                                ▼                         ▼
                           [YES: Refuse]            [NO: Proceed]
                     Returns INSUFFICIENT_EVIDENCE  Fast Sources: POST /ask/sources (~300ms)
                     + Official Scheme Contact            │
                                                    LLM Synthesis (Gemini 3.5 Flash)
                                                    + Short Voice Mode (max 2 sentences)
                                                          │
                                                    Claim-Lite Deterministic Verifier
                                                    - Exact quote substring match
                                                    - Number & date cross-checking
                                                    - Strict amount mismatch refusal
                                                          │
                                                    Grounding Verifier Guardrail
                                                    (gemini-3.5-flash-lite)
                                                          │
                                                    Status: SUPPORTED / INSUFFICIENT_EVIDENCE
                                                    needs_confirmation: true (digits/schemes)
                                                          │
                                                    Voice Output (Gnani Timbre TTS)
                                                    - Sentence 1 TTFA (~2.8s) pipelining
                                                    - Spoken Indic numerals ("ஆயிரம் ரூபாய்")
```

## Key Benchmarks & Verifiable Evidence

Every metric below is generated by committed scripts with reproducible parameters:

### 1. Hybrid OCR Benchmark (Tesseract vs. Chitrapathak-2)
- **Problem:** Tesseract misreads critical Indic numerals on low-DPI scanned government notes (e.g. reading `ரூ.1,000` as `4,000` or `7,000`).
- **Solution:** Hybrid Crop Mode pipeline (`scripts/run_hybrid_ocr.py`). Tesseract bounding boxes localize currency regions; tight bounding crops are re-read by `krutrim-ai-labs/Chitrapathak-2`.
- **Accuracy on Known Problem Pages:** **7/7 (100.0%)** for Chitrapathak-2 vs. **0/7 (0.0%)** for Tesseract.
- **Speedup:** Crop mode reduced inference from ~95s/page down to **~12s/page** (~8× speedup).
- **Corpus Coverage:** All 500 currency-flagged pages processed overnight; 263 numerical difference rows cataloged in [`docs/review/ocr_disagreements.csv`](docs/review/ocr_disagreements.csv).
- **Collection:** Built clean research collection `pakkam_chitra` (2,918 chunks, 4,449 vectors in Qdrant).
- **Full Report:** [`docs/review/ocr_benchmark_report.md`](docs/review/ocr_benchmark_report.md).

### 2. Retrieval Ablation Study
Evaluated on the `pakkam_chitra` collection across 194 draft questions via `scripts/ablate_retrieval.py`:

| Retrieval Mode | Sparse Lexical | Dense Vector | Cross-Encoder Reranker | Recall@5 (%) | Median Retrieval Time |
| :--- | :---: | :---: | :---: | :---: | :---: |
| **Keyword Only** | Yes | No | No | 67.5% | 195.6 ms |
| **Dense Only** | No | Yes | No | 94.8% | 52.1 ms |
| **Hybrid (Dense + Sparse)** | Yes | Yes | No | 94.8% | 215.6 ms |
| **Hybrid + BGE Reranker v2** | **Yes** | **Yes** | **Yes** | **98.7%** | **384.3 ms** |

- **Full Report:** [`docs/review/RETRIEVAL_ABLATION_REPORT.md`](docs/review/RETRIEVAL_ABLATION_REPORT.md).

### 3. Refusal Safety Calibration Curve
Swept across confidence thresholds $[0.20, 0.50]$ on 194 draft questions (`scripts/evaluate_refusal_curve.py`):
- **Active Default Threshold (`0.35`):** Achieves **87.1% overall routing accuracy**, correctly refusing **92.5% (37/40)** of ungrounded queries with a **14.3% (22/154)** false-refusal rate.
- **Full Report:** [`docs/review/REFUSAL_THRESHOLD_CURVE.md`](docs/review/REFUSAL_THRESHOLD_CURVE.md).

### 4. Voice-Loop Timing & Sentence Pipelining (TTFA)
Evaluated end-to-end via `scripts/voice_loop_timing.py` and `scripts/test_sentence_speech.py`:

| Processing Stage | Latency | Cumulative Time | Notes |
| :--- | :--- | :--- | :--- |
| **1. STT (Gnani Prisma REST)** | 1,320.4 ms | 1.32 s | 16 kHz WAV audio input |
| **2. Search (Dense + Sparse)** | 215.6 ms | 1.54 s | Qdrant `pakkam_chitra` collection |
| **3. Reranker (BGE-Reranker-v2)** | 236.8 ms | 1.77 s | Top 3 chunk selection |
| **4. Short Voice LLM** | 3,850.0 ms | 5.62 s | 2-sentence maximum, no markdown |
| **5. Sentence 1 TTS (Gnani Timbre)** | 2,795.1 ms | **8.42 s (TTFA)** | First audio played immediately |
| *Sentence 2 TTS (Background)* | *3,195.8 ms* | *—* | Pipelined during Sentence 1 playback |

- **Monolithic Loop Time:** ~14.2s.
- **Pipelined Time-to-First-Audio (TTFA):** **~8.4s – 9.2s** (~40% reduction in perceived wait time).
- **Full Reports:** [`docs/review/VOICE_LOOP_TIMING.md`](docs/review/VOICE_LOOP_TIMING.md) and [`docs/review/SENTENCE_SPEECH_REPORT.md`](docs/review/SENTENCE_SPEECH_REPORT.md).

### 5. Verified Fact Cards Evaluation
Evaluated via `scripts/fact_card_eval.py` across core scheme queries and unanswerable questions:
- **Card Precision:** **100.0%** (0 false card matches across 40 unanswerable draft questions).
- **Latency:** **<50 ms** (bypasses LLM entirely; 0 LLM calls consumed).
- **Human Provenance:** Every card requires `verified_by` and citing official document + page.
- **Audio Pre-caching:** Audio generated offline via `scripts/make_card_audio.py` for immediate playback.
- **Full Report:** [`docs/review/FACT_CARD_EVAL.md`](docs/review/FACT_CARD_EVAL.md).

### 6. BhashaShield Voice Safety & Speech Retrieval
Evaluated via `scripts/speech_error_test.py` across 31 read-speech clips (Kathbath dataset):
- **Document Retrieval Accuracy:** **90.3% (28/31)** matched the correct official scheme document.
- **Page Retrieval Accuracy:** **87.1% (27/31)** retrieved the exact official target page.
- **Voice Safety Guardrails:** Short transcripts (<5 chars) trigger immediate clarification; all answers involving numbers or scheme names return `needs_confirmation=True` so users confirm before acting.
- **Full Report:** [`docs/review/LANGUAGE_TABLE.md`](docs/review/LANGUAGE_TABLE.md).

### 7. Deterministic Claim-Lite Verification
Implemented in `src/schemebot/generate/claims.py`:
- Deterministically verifies exact citation quote substring containment within retrieved chunks.
- Parses numbers, percentages, dates, and frequency intervals (monthly, yearly, one-time).
- If any numerical or currency claim is not grounded in the cited chunk, the answer is forced to `status="INSUFFICIENT_EVIDENCE"`.
- Unit-tested via `tests/test_claims.py` (5 unit tests).

### 8. Git Secrets & Fresh Clone Audit
- Scanned 139 commits and 223 tracked files via `scripts/scan_git_secrets.py`: **0 API keys, credentials, or audio files tracked in git**.
- Full test suite passes on clean clone with zero missing dependencies: **55 / 55 tests pass in 18s**.

## API Contract Specification

FastAPI endpoints served at `http://localhost:8000`:

### `POST /ask`
Request:
```json
{
  "question": "புதுமைப்பெண் திட்டத்தின் கீழ் மாணவிகளுக்கு மாதந்தோறும் எவ்வளவு உதவித்தொகை வழங்கப்படுகிறது?",
  "voice_mode": false
}
```
Response:
```json
{
  "answer": "புதுமைப்பெண் திட்டத்தின் கீழ் உயர்கல்வி பயிலும் மாணவிகளுக்கு மாதந்தோறும் ரூ.1,000 உதவித்தொகை வழங்கப்படுகிறது. [1]",
  "status": "SUPPORTED",
  "path": "rag",
  "needs_confirmation": true,
  "citations": [
    {
      "id": 1,
      "document": "Higher Education Department Policy Note 2024-2025",
      "doc_id": "tn-hedu-policy-note-2024-ta",
      "page": 33,
      "snippet": "மூவலூர் இராமாமிர்தம் அம்மையார் நினைவு உயர்கல்வி உறுதித் திட்டத்தின் கீழ் மாதந்தோறும் ரூ.1,000/-...",
      "document_date": "2024-06-20",
      "source_url": "https://www.tn.gov.in/documents/dept/11"
    }
  ],
  "contact": null,
  "timings_ms": {
    "search": 215.6,
    "rerank": 236.8,
    "llm_answer": 3850.0,
    "verifier": 1378.5,
    "total": 5680.9
  }
}
```

### `POST /ask/sources` (Fast Sources-First Endpoint)
Returns official document citations in **~300 ms** using 0 LLM calls:
```json
{
  "query": "pm kisan samman nidhi amount",
  "passages": [
    {
      "doc_id": "pm-kisan-guidelines-en",
      "scheme": "PM-KISAN",
      "page_start": 3,
      "page_end": 3,
      "text": "Under the scheme, financial assistance of Rs. 6000/- per year...",
      "relevance": 0.884,
      "source_url": "https://pmkisan.gov.in"
    }
  ]
}
```

### Additional Endpoints
- `POST /ask/voice`: Form-data audio upload (`.wav`, `.mp3`), transcribes via Gnani Prisma, then executes the grounding pipeline.
- `POST /transcribe`: Transcribes voice to text immediately for front-end review.
- `POST /speak`: Synthesizes text to 24 kHz WAV via Gnani Timbre with amounts spelled out phonetically.
- `GET /health`: Healthcheck (`{"status": "ok"}`).
- `GET /sources`: Returns complete catalog of 18 policy documents with publication and retrieval dates.

## Quickstart & Execution

### Prerequisites
- Python 3.11+ (or Anaconda with PyTorch CUDA)
- Tesseract OCR (v5.5+ with `tam`, `hin`, `eng` language packs)
- GPU with $\ge 8$ GB VRAM recommended for local BGE embeddings and Chitrapathak-2

### Setup & Run
```powershell
# 1. Environment configuration
cp .env.example .env
# Edit .env with your SCHEMEBOT_GEMINI_API_KEY, SCHEMEBOT_GNANI_API_KEY, etc.

# 2. Install dependencies via uv
uv sync --extra api --extra store --extra eval --extra generate --extra gemini --extra ingest

# 3. Run automated test suite (521 unit & integration tests)
uv run pytest -q

# 4. Launch live API & web interface
$env:PYTHONPATH="src"
$env:SCHEMEBOT_QDRANT_COLLECTION="pakkam_chitra"
uv run python -m uvicorn schemebot.api.main:app --host 0.0.0.0 --port 8000
```

Access in your browser:
- **Web Chat App:** [http://localhost:8000/chat/](http://localhost:8000/chat/)
- **Portal Home:** [http://localhost:8000/](http://localhost:8000/)
- **Swagger Docs:** [http://localhost:8000/docs](http://localhost:8000/docs)
